# Всем домом

Бот и мини-приложение для домового чата в MAX: когда в доме пропадает вода, тепло или свет, соседи отмечают аварию в одной карточке, видят сроки по нормативам и ответ УК, а после устранения получают итог для всего дома.

**Одна авария — одна карточка.**

> Дома, УК и телефоны АДС — модельные данные. Нормативы (сроки, лимиты, ставки) — реальные, с основанием и датой проверки.

Статус: идёт разработка — бэкенд и бот волны 1 готовы и работают на симуляторе MAX, дальше волна 2. Полный README с порядком проверки появится к сдаче.

## Запуск одной командой

Нужны Docker и Docker Compose ≥ 2.24.

```bash
docker compose up --build
```

Поднимаются `db` (PostgreSQL 16), `migrate` (миграции и сиды), `api`, `worker` и `web` (Caddy). Файл `.env` не обязателен: по умолчанию включён режим `simulator` — без токена бота, с модельными данными.

| Адрес | Что |
|---|---|
| http://localhost:8080/health | Процесс жив |
| http://localhost:8080/ready | БД и миграции готовы |
| http://localhost:8080/api/v1/version | Версия сборки и включённые функции |

Остановка — `docker compose down`, с удалением данных — `docker compose down -v`.

Свои значения переменных: `cp .env.example .env` и правка. Не запускайте локально с боевым токеном в режиме `webhook`: это перепишет подписку боевого бота.

## Разработка без Docker

Нужны Node.js 24 (`.nvmrc`), pnpm 10 через corepack и PostgreSQL 16.

```bash
corepack enable
pnpm install
pnpm test
pnpm lint
pnpm typecheck
```

Миграции и сиды в локальную базу:

```bash
DATABASE_URL=postgres://localhost:5432/vsemdomom_dev pnpm db:migrate
```

## Работа с данными

Храним только идентификатор MAX, дом, квартиру и роль; имена, телефоны и текст заявления не храним и не логируем. В чате дома — только число отметок по подъездам. Удалить данные — `/delete` в боте. Подробно — `docs/DATA.md`; политика для жителей — страница `/privacy` (например, http://localhost:8080/privacy).

## Структура

| Каталог | Что |
|---|---|
| `packages/core` | Доменная логика без ввода-вывода: статусы, сроки, расчёты |
| `packages/shared` | Контракт API (zod-схемы), перечисления, словарь `ru.json` |
| `apps/api` | Fastify: REST, webhook MAX; worker — отдельная точка входа |
| `apps/miniapp` | Мини-приложение (React, MAX UI) |
| `db/migrations`, `seeds` | Миграции drizzle и модельные данные |
| `infra` | Caddy, override для стенда, сертификаты Минцифры |
| `design/handoff` | Пакет дизайна |
| `docs` | Контракт API (`docs/api/openapi.yaml`), проверки DATA-API (`docs/api/DATA-API.yaml`), данные, проверки MAX, задачи потоков |
| `tools/data-api` | Валидатор DATA-API организаторов (запускается в CI) |
