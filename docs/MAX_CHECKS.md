# Проверки MAX

Два слоя проверок: сверка с официальной документацией (dev.max.ru и `schema.yaml` из github.com/max-messenger/api-schema) и ручные проверки на живом MAX. Пока строка не проверена на живом MAX, поведение считается непроверенным.

## 1. Сверка с документацией — 27.09.2026

Источники: dev.max.ru/docs-api (обзор, методы, объекты, клавиатура, уведомления о событиях, история изменений), dev.max.ru/docs/webapps (подключение, MAX Bridge, валидация), dev.max.ru/help/deeplinks, `schema.yaml` версии 0.0.33 (коммит `1a4a502` от 18.09.2026).
