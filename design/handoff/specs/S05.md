## S05. Авария (житель) · /incident/:id
### Зачем и кто
Анна: за 3 секунды понять — УК знает? когда дадут? что делать. Первая строка — IncidentHeadline.
### Раскладка
S/M: IncidentHeadline → услуга, «с 17:40 · 11 жителей», ModelDataBadge → контекстный баннер → сроки → статус УК → где → моё участие → хронология; ActionBar «Позвонить в АДС» закреплён. L: заголовок на всю ширину, ниже 2 колонки (слева сроки, статус, где, участие; справа хронология); StatusStepper горизонтальный. Альбом: ActionBar в конце.
Брейкпоинты: XS 320–359 (поля 12), S 360–479 (поля 16), M 480–839 (колонка до 640), L ≥ 840 (контент до 880 / список + деталь). Короткий экран ≤ 480 px: заголовок Title, ActionBar в конце контента. Безопасные зоны — `env(safe-area-inset-*)`; высота — от `dvh`/`WebApp.getViewportSize()`.

### Крайние случаи
Срок истёк — DeadlineChip expired «истёк в 18:10», без оценок. Нет ориентира — в заголовке срок по нормативу. Нет нормы — «норматив не установлен». Авария через полночь — даты у времени.
Общие: длинный адрес — 2 строки и многоточие, полный — по касанию; 99+ в чипах; > 7 подъездов — прокрутка EntranceCounter на S; нет нормы — «норматив не установлен», таймера нет; нет ориентира УК — показываем срок по нормативу; авария через полночь или границу месяца — даты у времени («вчера 22:10», «30.09 23:40»), месячный лимит по каждому месяцу; медленная сеть — Skeleton, через 8 с «Загружаем дольше обычного» + «Повторить»; устаревшая ссылка — S12 «Ссылка устарела»; функция выключена флагом — кнопок нет, прямой переход — S12 feature_off.

### Доступность
Порядок: заголовок → баннер → сроки (чип → основание) → статус → где → участие → хронология → ActionBar. Timeline — ol; StatusStepper — aria-current=step. На L — «Скопировать номер АДС». Цели касания ≥ 44 × 44, между целями ≥ 8 px; текст до 200 % без горизонтального скролла на 320 px; фокус — 2 px `--controls-active`.
