## U02. Авария (УК) · /uk/incident/:id
### Зачем и кто
Ольга: масштаб по подъездам и этажам, сроки, одно следующее действие статуса — ответ всему дому одним нажатием.
### Раскладка
S/M: IncidentHeadline → услуга/адрес/ModelDataBadge → сетка подъезд × этаж → сроки → жители → хронология; ActionBar закреплён: следующий шаг (primary) + «Другой статус». L: правая часть U01; действия статуса строкой под заголовком (primary + «Другой статус» + «Смотреть как житель»), две колонки контента. Альбом: ActionBar в конце.
Брейкпоинты: XS 320–359 (поля 12), S 360–479 (поля 16), M 480–839 (колонка до 640), L ≥ 840 (контент до 880 / список + деталь). Короткий экран ≤ 480 px: заголовок Title, ActionBar в конце контента. Безопасные зоны — `env(safe-area-inset-*)`; высота — от `dvh`/`WebApp.getViewportSize()`.

### Крайние случаи
> 4 подъездов — сетка прокручивается по горизонтали на S. Дом из 17 этажей — сетка прокручивается внутри карточки. Две УК-вкладки одновременно — последний статус выигрывает, хронология показывает оба.
Общие: длинный адрес — 2 строки и многоточие, полный — по касанию; 99+ в чипах; > 7 подъездов — прокрутка EntranceCounter на S; нет нормы — «норматив не установлен», таймера нет; нет ориентира УК — показываем срок по нормативу; авария через полночь или границу месяца — даты у времени («вчера 22:10», «30.09 23:40»), месячный лимит по каждому месяцу; медленная сеть — Skeleton, через 8 с «Загружаем дольше обычного» + «Повторить»; устаревшая ссылка — S12 «Ссылка устарела»; функция выключена флагом — кнопок нет, прямой переход — S12 feature_off.

### Доступность
Порядок Tab: главная кнопка → «Другой статус» → сетка → сроки. Меню — стрелки, Esc закрывает. Сетка — table с rowheader/columnheader. Цели касания ≥ 44 × 44, между целями ≥ 8 px; текст до 200 % без горизонтального скролла на 320 px; фокус — 2 px `--controls-active`.
