# chat-templates.md — сообщения бота C01–C09

Формат: текст ≤ 4000 символов, markdown; первая строка — жирная (`**…**`). Правила: первая строка — статус УК и ближайший срок; ≤ 8 строк; без имён и номеров квартир; только абсолютное время; «Модельные данные» — последней строкой. Маркер статуса — только в начале первой строки, статус назван словами, в кнопках маркеров нет.
Кнопки в макетах — высота 36 px, радиус 10 (реальный размер задаёт клиент MAX). Лимиты клавиатуры: ≤ 30 рядов, ≤ 210 кнопок, ≤ 7 в ряду; ≤ 3 в ряду, если есть `link` / `open_app` / `request_contact` / `request_geo_location`; подпись ≤ 128 символов. Наш лимит длины: ряд из 2 — ≤ 18 символов, из 3 — ≤ 12, из 4–7 — цифры или 2–3 символа.
Ключи текста — `copy/ru.json` (`bot.*`). Референс — `BotMessage.dc.html`, `Chat Messages.dc.html`.

| Маркер | Статусы |
|---|---|
| 🔴 | Открыта |
| 🟠 | Принята, Бригада на месте, Локализована |
| 🔵 | Проверяем |
| ⚠️ | Расхождение, Закрыта с расхождением |
| ✅ | Закрыта |
| 🔗 | Объединена |

## C01 · Панель дома в закрепе (правится)
```
**🏠 Дом {house} · {address}**
Активные аварии: {count} — {service_no_lower} с {time}      | или «Активных аварий нет»
Последний итог: {date} {service_lower}, {result}
В чате {members} участников
Модельные данные
[Сообщить об аварии]   open_app  payload n_{houseId}          (18 симв.)
[Мой дом]              open_app  payload h_{houseId}
```

## C02 · Карточка аварии (одно сообщение, правится; ≤ 6 строк)
```
**{L1 по статусу}**
{L2 по статусу}
С {start} · отметились {n} {residents}: подъезд 2 — 6, подъезд 3 — 5
Из них не подтверждены: {unconfirmed}
У вас тоже нет воды? Нажмите свой подъезд:
Обновлено {updated} · Модельные данные
[1] [2] [3] [4]                    callback join:{n}   (≤ 7; > 7 подъездов → одна [У меня тоже] callback join:0)
[Не знаю подъезд] [Не у меня]      callback join:0 / not_me                 (15 / 9 симв.)
[Подтверждаю] [Бригады нет]        callback crew_yes / crew_no — только в «Бригада на месте»
[Подробнее и сроки]                open_app i_{incidentId}
```

| Статус | L1 | L2 |
|---|---|---|
| Открыта | 🔴 {service_no} · УК ещё не ответила | Срок ответа УК по нормативу — до {t} (ПП № 416, п. 13) |
| Открыта, срок истёк | 🔴 {service_no} · УК ещё не ответила | Срок ответа по нормативу истёк в {t} · телефон АДС в «Подробнее» |
| Принята | 🟠 {service_no} · УК приняла, ориентир {eta} | Локализовать до {t} · устранить до {fix} (ПП № 416, п. 13) |
| Бригада на месте | 🟠 {service_no} · бригада на месте с {t} | Ориентир УК {eta} |
| Локализована | 🟠 {service_no} · авария локализована в {t} | Ориентир УК {eta} |
| Проверяем | 🔵 {service} · УК отметила устранение в {t} | Ответьте на вопрос ниже: есть ли у вас вода |
| Расхождение | ⚠️ {service} · у {n} {flats} воды нет | УК отметила устранение в {t}. Им пришла подсказка в личку |
| Закрыта в норматив | ✅ Закрыта · {service_lower} есть | {dur} по отметке УК, в пределах нормы. Итог ниже |
| Закрыта сверх нормы | ✅ Закрыта · {service_lower} есть | У {n} {flats} перерыв {dur}, сверх месячной нормы. Итог ниже |
| Закрыта с расхождением | ⚠️ Закрыта · у {n} {flats} восстановление не подтверждено | За 72 ч ответа «есть вода» не пришло. Итог ниже |
| Объединена | 🔗 Эта авария объединена с другой | Сроки и отметки — в актуальной карточке; клавиатура — [Открыть актуальную] open_app i_{newId} |

После закрытия: строки 3 и 6 остаются, 4–5 убираются; клавиатура — одна [Итог и перерасчёт] open_app r_{id}.
Ответ нажавшему (`POST /answers`, notification): «Вы отметились: подъезд {n}. Ответ УК пришлём в личку» / незарегистрированному — «… Чтобы получать ответ УК и итог, откройте бота {bot_link}». ⚠ проверить, что уведомление видит только нажавший.

## C03 · Вопрос о восстановлении (второе новое сообщение)
```
**{restore_question}**
УК отметила устранение в {t}. Ответ поможет увидеть, у всех ли всё в порядке.
Модельные данные
[Да, есть] [Нет]           callback restore:yes / restore:no
[{bad_label}]              callback restore:bad — отдельным рядом: «Есть, но плохая» 15 симв. > 12 для ряда из 3
```
| Услуга | restore_question | bad_label |
|---|---|---|
| Холодная / горячая вода | Холодная / Горячая вода вернулась? | Есть, но плохая |
| Отопление | Батареи снова тёплые? | Чуть тёплые |
| Свет | Свет есть? | Мигает |
| Канализация / газ / протечка | Канализация работает? / Газ подаётся? / Протечку устранили? | — (ряд не показываем) |
Повторное «Устранено» — правка этого же сообщения: вторая строка «Повторная проверка, УК: {t}».

## C04 · Итог (третье новое сообщение, reply на карточку, 7 строк)
```
**Итог: {service_lower}, Дом {house}**
По отметке УК: {from}–{to}, {dur}
Отметились {n} {flats}. У {late} вода вернулась позже, в {t}
У этих {late} {flats} за {month} {total} перерывов при норме {limit}
Им можно подать заявление на перерасчёт
Копию акта о нарушении качества выдают по запросу за 3 рабочих дня (ПП № 416, п. 34)
Это расчёт по нормам · Модельные данные
[Оформить перерасчёт]      open_app r_{id}
```
Без превышения — строки 4–5 заменяются на «Перерывы в пределах нормы — перерасчёт не положен».

## C05 · Личка
| Шаблон | Текст (ключ) | Клавиатура |
|---|---|---|
| Приветствие (`bot_started`) | bot.dm.welcome.l1–l2 | [Согласен] callback pdn:yes · [Политика данных] link |
| Кто вы в квартире | bot.dm.role, bot.dm.role.why | [Собственник][Снимаю] / [Соцнайм][Член семьи] callback role:* |
| Номер квартиры | bot.dm.flat; ошибка bot.dm.flat.error | — (текстом) |
| Вступить в чат | bot.dm.join + адрес + Модельные данные | [Вступить в чат дома] link (поле `link` чата) |
| Главное меню | bot.dm.menu, bot.dm.menu.l2 | [Сообщить об аварии] callback report · [Мой дом] open_app h_{id} |
| Сообщить в личке | bot.dm.report.what / when / where | услуги по 2 в ряд (4 ряда; «2 ряда по 4» из ТЗ нарушает лимит длины) · [Сейчас][Указать время] · [Квартира][Подъезд][Дом] |
| Инструкция АДС | bot.dm.ads.* | [Позвонить] link tel: ⚠ · [Ввести номер заявки] · [Не дозвонился] — по одной в ряд |
| Статус изменился | bot.dm.status (маркер + статус словами) | [Подробнее] open_app · [Не присылать] callback mute |
| Таймер | bot.dm.timer.soon / expired | [Подробнее] open_app |
| Воды нет — что делать | bot.dm.nowater.* | [Я сообщил в АДС] callback · [Как составить акт] open_app a_{id} (волна 3; при выключенном флаге кнопку не показываем) |
| Заявление | bot.dm.statement + текст + pdn.not_stored | [Скопировать] clipboard |
| Удалить данные (`/delete`) | bot.dm.delete, bot.dm.delete.text | [Удалить][Отмена] callback |
Сообщения лички с домом, УК или телефоном АДС заканчиваются строкой «Модельные данные».

## C09 · Бот добавлен в чат
```
Здравствуйте. Я «Всем домом»: собираю аварию в доме в одну карточку со сроками по нормативам.
Чтобы начать, сотрудник УК привязывает чат к дому, а бот должен быть администратором чата
[Привязать к дому]    open_app c_{oneTimeToken} → U03 (привязка)
```
Нажал житель → notification «Привязать чат может только сотрудник УК. Вы можете сообщить об аварии в личке с ботом».

## C06 · Ответ на «нет воды» (волна 3, F13; не чаще раза в 10 минут на чат)
```
Похоже, в доме нет воды. Сообщите об этом одной кнопкой — соседи увидят в карточке
Модельные данные
[Присоединиться к аварии] [Сообщить об аварии]   callback join:0 · open_app n_{houseId}
```
Одним рядом, подпись в две строки. ⚠ Перенос и высоту кнопки задаёт клиент MAX: если на живом MAX подпись обрезается, запасной вариант — два ряда или короткие «У меня тоже» / «Сообщить». Если открытой аварии нет — только [Сообщить об аварии].
```
```

## C07 · Опросы (волна 3, F14; ≤ 1 в сутки на дом, не в тихие часы 22:00–08:00)
```
**Как вода сейчас?**                                   | **Тепло ли у вас?**
Опрос УК по дому {house}. Ответ видит только УК…       | Опрос УК по дому {house}. После ответа бот спросит подъезд
Опрос не заменяет обращение в АДС · Модельные данные
[Нормально] [Ржавая] [Слабый напор]  callback poll:*   | [Тепло] [Чуть тёплые] [Холодные] callback heat:*  (≤ 12 симв.)
                                                       | [1] [2] [3] [4] callback heat_ent:{n}
```
«Тепло ли у вас?» — один раз за сезон. Результат — тепловая карта U05.

Модельные данные
