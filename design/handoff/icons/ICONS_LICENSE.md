# Иконки

MAX UI 0.5.0 содержит 6 глифов (шеврон, крестики, поиск) — используются из пакета. Остальные — **Lucide 0.469.0**, лицензия ISC (https://lucide.dev/license), файлы получены из `lucide-static@0.469.0` (unpkg). В SVG этого пакета толщина линии заменена на **1,75 px** (ТЗ 2.3), цвет — `currentColor`. В коде: `lucide-react` с `strokeWidth={1.75}`. Официальные иконки MAX из `MAXUI-Figma.fig` при появлении заменяют эти.
